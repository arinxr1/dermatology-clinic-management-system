# Dermatology Clinic Management System 🏥

A clinic management system developed using MySQL, Python, and FastAPI. The project is currently under development.

## Implemented Features
- Relational MySQL database for clinic operations.
- REST APIs for retrieving services, doctors, and appointments.
- Appointment booking with scheduling conflict detection.
- API testing and documentation using Swagger UI.

## Tech Stack
Python · FastAPI · MySQL · SQL · Swagger UI

## Next Steps
- Appointment rescheduling and cancellation.
- Authentication and role-based access control.
- Frontend development and API integration.
